## 文件与引用面

| 文件 | 是什么 | 被谁引用 |

| `imbot.png` / `imbot_en.png` | IM 机器人页的整屏实拍（中 / 英） | [README.md](../../README.md) · [README.en.md](../../README.en.md) 的「界面」段 |

- 三组界面图**中英各一套**，只有界面语言不同：中文 README 引中文那套，英文 README 引 `_en` 那套。
- 界面图渲染在详情页的**描述与行列表之间**（宿主 `plugins.bundle.config` 槽），所以图里应当能看到插件的标题与描述。
- 换图不动 `width`（整屏那张满宽、并排两张各 `49%`、二维码 `240`），只有改名才要同步两份 README。
- `docs/` **不在 [package.json](../../package.json) 的 `files` 里**：图不进 npm 包；但 npm 页面的 README 图指向仓库默认分支的原始地址 —— **换图等于同时改线上所有版本的展示**。

## 风格基准

新图与现有图保持一致；要不要换风格是维护者的决定，截图的人不自行改。

| 项 | 基准 |
| --- | --- |
| 尺寸 | 整屏图**不设 viewport**，用自然视口拍 —— 物理产物自然就是 **2449x1223**（CSS 1484x741 × dpr 1.65）；**别调 `setViewportSize`**，那会压掉 dpr、界面缩到约 60%。元素图按内容取景，中英两张一致 |
| 侧边栏 | **画面里带左侧栏的整屏 / 宽幅图，按快门前必须收起左侧栏** |
| 背景 | 空会话 |
| 主题 | 浅色 |
| 界面语言 | 一份英文一份中文，除语言外画面完全一致 |

**侧栏为什么必须收起**：展开的左侧栏列的是维护者真实的**会话标题与工作区名** —— 那是别人的工作内容，不是装饰；门面图是给外人看的，带出去就是泄露。
收起状态下点不到 `Plugins`，所以顺序也是死的：**展开导航 → 走到目标画面 → 收起侧栏 → 按快门**（见 [AGENTS.md](AGENTS.md) 第 4 步）。
元素图（对话框、行内展开）的取景里没有侧栏，不受这条约束。

## 变更影响路由

- 改界面渲染面（文案 / 结构 / 样式 / 可见状态）→ **必须同批重拍**受影响的那组图，中英一起。
- 换图本身 → 两份 README 无需改；只有文件改名才要同步两份 README 与本目录两份文档。
- 二维码换了 → 只换文件，两份 README 不动。
