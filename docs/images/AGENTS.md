# docs/images/ — 规则层

只讲**在这里要怎么干**；目录里有什么、被谁引用、图长什么样 → [README.md](README.md)。
本仓目前没有根 `AGENTS.md`：产品语义与领域词汇以 [CONTEXT.md](../../CONTEXT.md) 为准，本文件只管这些门面图。

## 什么时候必须重拍

判据是「图里的界面有没有变」，不是「改了哪个文件」。

必须重拍：

- 详情页 `plugins.bundle.config` 槽里的配置区：字段增删、顺序、按钮、状态行
- 「上下文增强」那一处的文案与控件形态
- 「访问模式」对话框的标签页、卡片、选择行、底部按钮
- 详情页的导航与文案：插件标题 / 描述 / 版本 / 频道 tab

不必重拍：

- 类型与注释（只活在编译期）
- 行为等价的内部重构：抽常量、改名、等价重写
- `README` / `CONTEXT` / 测试 / 构建配置
- 二维码：与界面无关，只有群或账号换了才换

拿不准时按「必须重拍」办：图的成本低于一张与界面不符的图。

## 完成定义

- 改渲染面的改动，**要么同批带重拍图，要么在 commit body 里写明为什么不重拍**。
- 图与文案分成两个提交，会留下「文案已改、README 里的图还是旧的」的窗口。

## 怎么重拍

截图会改**全局设置**（界面语言），所以第 0 步是问，不是动手。

0. **先问再动**，问的时候说清三件事，再等维护者确认：要占用浏览器几分钟；会临时切界面语言、结束切回；**截图期间请别改语言 / 主题 / 模型等全局设置** —— 它们直接进画面。
1. **用自己的标签页**，不动维护者的标签页；结束时关掉。
2. **开一个新会话**（隐私要求）：停在旧会话上，聊天区里就是正在进行的那段对话与工具调用。
3. 进侧边栏 **Plugins → Installed → `@xmanrui/dsh-im`**（列表里的短名是 `im`，**不是**全包名；详情页判据是 `[data-plugin-name]` 显示全包名，配置段是 `[data-plugin-config]`）：
   - `imbot*.png`：详情页**整屏** —— 面包屑、插件标题与版本、频道 tab 一排、机器人账号卡片。
   - `Context_enhancement*.png`：**元素图** —— 点开「上下文增强」那一行后，对展开出来的那块取景。
   - `access_mode*.png`：机器人「更多设置」→ 访问设置标签页，对**对话框**取景。
4. **按快门前收起左侧栏**（隐私硬规则，独立一步）：展开的左侧栏列的是维护者真实的**会话标题与工作区名** —— 那是别人的工作内容，不是装饰，门面图不能带出去。
   收起状态下点不到 `Plugins`，所以顺序是死的：**展开导航 → 走到目标画面 → 收起侧栏 → 按快门**，不能图省事一开始就收。
5. **长元素先解裁剪，再做元素截图**：从锚点往上把 `overflow` 清成 `visible`、`max-height` 清成 `none`，直到 `body`；再对**最小祖先**做元素级截图。
6. **语言**：界面当前是 English —— 先拍全部 `_en`，再切成中文拍中文版，最后**切回 English**。切语言会让页面重载，切完重新走一遍第 3、4 步。
7. **交还**：关掉自己的标签页 → 把当前会话切回维护者原来那个 → 告诉他可以用了。

## 已知约束（重拍实测）

- **整屏图不要设置 viewport**：用**自然视口**拍，产出的物理尺寸自然就是 **2449x1223**（CSS 视口 1484x741 × devicePixelRatio 1.65）。
  **不要 `setViewportSize(2449, 1223)`** —— 它会把 dpr 压成 1，界面只剩原生约 60%，维护者那句「界面缩小了」说的就是这个。
- **devicePixelRatio 本来就是 1.65**：不要去动它，也不要把它压成 1。靠 CDP 改密度那条路被 TabbitDance 拒（`Command rejected`），1.65 是唯一正常值，2x 不可得。
- **只有拍长元素时才临时调 viewport，且只调高度**（宽度不要动），拍完立刻还原。
- **落盘一律绝对路径**：运行器里 `process.env.TEMP` 是 `undefined`，相对路径会写进浏览器安装目录，事后很难找回来。
- **两种截图的落点不同**：`locator.screenshot({ path })` 是原生 Playwright，**照写你给的路径**；`page.screenshot()` 会被浏览器运行时接管，落到它的 artifacts 目录，真实路径只在返回值里。
- 每次提交是全新作用域，**元素都要重新定位**；切语言、切页面之后尤其如此。

## 验收

- **每张都用 `read_image` 亲自看**，不要只看文件大小
- 语言正确：`_en` 图里是英文，其余是中文；三组各两张除语言外构图一致
- **画面里左侧栏是收起态**：看不到任何会话标题、工作区名或对话内容
- 不出现真实凭据、真实 Base URL、真实聊天对象标识（掩码形态可接受）
- 文件确实被两份 README 引用（覆盖后跑一次链接校验）
