## 4. 文件依赖（单向无环）

```text
conversation-role-store
  ↑                     ↑
preset-command   workspace-session
  ↑                     ↑
bridge.mjs ─── index.js/api.js ─── host/controller
  ↑
message-utils.mjs（conversation key）
```

`conversation-role-store` 不反向依赖预设命令或会话解析；`preset-command` 与 `workspace-session` 都只访问它的读取接口。

## 5. 数据流 / 状态机

```text
用户消息 → bridge 解析 conversationKey
   │
   ├─ 命令路由：/role /roles → preset-command.runRoleCommand
   │         → 读 conversation-role-store
   │         → 写 override / role-session
   │
   └─ 普通消息 → workspace-session.askInWorkspaceSession
            → 解析角色覆盖（botId+convKey）
            → key = convKey + rolePresetId
            → 命中角色会话则续接，否则用角色 Preset 创建
            → 注入 Workspace（机器人的，固定）
            → 注入 Agent Preset（角色覆盖 ?? 机器人默认 ?? Host 默认）
```

状态：

```text
conversationKey 无 override → 沿用 bot 默认 preset（同 4.9.0 行为）
conversationKey 有 override → 使用 override 的 preset；session 按 convKey+role 区分
/role --default → 删除 override，回退 bot 默认
```

## 6. 配置与接口契约

### 持久化文档（conversation-role-store）

```json
{
  "version": 1,
  "overrides": {
    "<botId>": {
      "<conversationKey>": "<presetId>"    // null 表示已清除
    }
  },
  "roleSessions": {
    "<botId>": {
      "<conversationKey>:<presetId>": "<sessionId>"
    }
  }
}
```

### 命令

```text
/roles               列出可用 Agent Preset + 当前 conversation 的覆盖
/role                查看当前 conversation 角色
/role <presetId>     设置当前 conversation 覆盖
/role --default      清除覆盖
```

### RPC（client ↔ host）

```text
bot.role.get         { botId, conversationKey } → { preset, catalog }
bot.role.set         { botId, conversationKey, presetId } → snapshot
bot.role.default     { botId, conversationKey } → snapshot
```

## 7. 扩展点

- 渠道扩展：核心在 shared，各渠道 bridge 只加命令路由与调用 `askInWorkspaceSession`（已有）。
- thread 扩展：conversationKey 已支持 thread，角色覆盖天然按 thread 隔离。
- Project Registry：可在 conversation-role-store 上层叠加，不影响本实现。

## 8. ADR 简表

| 决策 | 理由 |
| --- | --- |
| 角色 = Agent Preset 别名 | DSH 已有 Preset，避免第二套配置和迁移成本 |
| override 存 `botId+conversationKey` | 会话级隔离精确；保留 bot 默认 Preset 作兜底 |
| 角色会话 key = `convKey:presetId` | 切回角色恢复原上下文，避免上下文污染 |
| 不引入 Project Registry | 最小 PR，先解决一总群多项目+多角色 |
| 核心放 shared 层 | 九个渠道复用 `/preset` 命令，不写孤立实现 |
