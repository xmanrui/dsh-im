## P1 ConversationRoleStore

目标：新增 `src/channels/shared/conversation-role-store.mjs`，为每个 bot 保存 conversation 级 Preset override 和角色会话映射。

任务：
- [x] 定义文档 schema `{version:1, overrides, roleSessions}`，normalize 校验 ID 与 key
- [x] 原子持久化（tmp+rename，0600），复用 StateStore 模式
- [x] 接口：`overrideFor(botId, convKey)` `setOverride` `clearOverride(botId, convKey)` `roleSessionFor(botId, convKey, presetId)` `setRoleSession` `clearRoleSession` `clearBot(botId)` `remove`
- [x] bot 生命周期：`clearBot(botId)` 在机器人删除/解绑/Workspace 切换时调用（production.mjs deleteState）
- [x] 白名单 ID 校验，拒绝控制字符和任意路径
- [x] 测试：`test/channels/shared/conversation-role-store.test.mjs`

验收：
- [x] override/roleSessions 可持久化并回读
- [x] 旧/空文件返回默认，不抛错
- [x] `clearBot` 清空该 bot 全部 override 与 role session
- [x] 写失败时内存与持久状态一致
- [x] 文件权限 0600

## P2 /role /roles 命令语义

目标：在 `src/channels/shared/preset-command.mjs` 增加角色命令，不改动现有 `/preset` 语义。

任务：
- [x] `isRoleCommand(text)`（`/roles` `/role`）
- [x] `runRoleCommand(text, harness, state, key, options)`：
  - `/roles` 列出可用 Agent Preset + 当前 conversation 覆盖
  - `/role` 查看当前覆盖
  - `/role <presetId>` 设置覆盖，校验 Preset 存在于 Host catalog
  - `/role --default` 清除覆盖
- [x] 覆盖状态读写 `conversation-role-store`，会话级，不动 `agentPresets[botId]`
- [x] 错误处理与 i18n，不泄露本机路径（新增 `role-command.mjs` 独立文件，未改动 `/preset`）
- [x] 测试：`test/role-command.test.mjs`

验收：
- [x] `/roles` 不创建会话、不触发模型
- [x] `/role <id>` 只改当前 conversation，不影响 bot 默认，也不影响其他 conversation
- [x] `/role --default` 清除覆盖，回退 bot 默认
- [x] 不存在/损坏 Preset 被拒绝
- [x] 带图片/文件时拒绝

## P3 会话创建注入角色 Preset

目标：让 `askInWorkspaceSession` 与 bot-scope `createSession` 按“角色覆盖 → bot 默认 → Host 默认”决定 Preset，并把会话 key 变为 `convKey:presetId`。

任务：
- [x] workspace-session：解析 `conversation-role-store` 的 override；存在则使用；不存在沿用现状
- [x] 会话 key：`convKey` 无 override 时沿用 `convKey`（保持 4.9.0 兼容）；有 override 时用 `convKey:presetId`
- [x] bot-scope `createSession`：Preset 取显式传入的角色覆盖，否则 bot 默认
- [x] 角色会话持久化：`setRoleSession` 记录 `convKey:presetId → sessionId`
- [x] Workspace 仍然只来自 `workspaceFor(botId)`（不能被角色覆盖）
- [x] 并发 fence 与 generation 逻辑保持：切换/清空不能把旧 Session 写回
- [x] 测试：`test/channels/shared/workspace-session-role.test.mjs`

验收：
- [x] 有覆盖时新会话用 override Preset 且会话 key 含角色
- [x] 无覆盖时行为与 4.9.0 一致（关键回归）
- [ ] `/model` 创建空白会话也用角色覆盖（后续可叠加，当前模型命令直接 createSession 未走角色解析）
- [x] 角色不能改变 Workspace
- [x] Workspace 切换清除该 bot 全部角色会话

| 风险 | 影响 | 缓解 |
