# PR #186：同步卡片修复与飞书实测

修复分支：`codex/fix-feishu-session-sync`，基于 `ebde256`（4.19.0）。

## 修复范围

只调整飞书 Session 同步卡片及其与文字同步的衔接，沿用现有卡片渲染、历史读取和文字投递能力，不增加依赖、开关或通用任务框架。

- 按真实 `sessionId + turn` 区分回合；30 秒定时器只查询历史，不把静默当成完成。只有真实结束事件或历史结束记录才收尾。
- 按渠道、机器人和目标隔离卡片投递。文字同步等待完整答案实际到达卡片后才跳过该目标；创建或最后更新失败时保留文字兜底。
- 删除重复恢复循环。每次成功更新卡片都保存快照及恢复所需的内容块；恢复时沿用原卡片，并读取历史中的最终答案，避免旧快照覆盖新答案。已有封存分片保留，成功后再清理记录。
- 运行中重载后继续使用原卡片；恢复投递失败时保留快照重试。无法识别的旧记录保留，不生成空卡片覆盖其内容。
- 普通 IM 回合在事件入队前记录所属关系，避免异步队列误生成同步卡片。正常私聊、群聊、其他渠道、模型选择、审批与延迟投递沿用既有路径。
