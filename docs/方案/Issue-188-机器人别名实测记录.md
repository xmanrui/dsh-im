# Issue #188：机器人别名实现与实测

需求：[支持机器人自定义别名，保留原名称并可随时恢复](https://github.com/xmanrui/dsh-im/issues/188)。

## 实现

- 11 个 IM 渠道共用名称旁的铅笔入口与别名弹窗。弹窗显示只读原名称，支持保存、取消、恢复原名称；清空后保存同样恢复原名称。
- 别名只覆盖管理界面显示名称，原平台名称和机器人身份保留。最长 80 个字符，去除首尾空白，拒绝换行和控制字符。
- 复用各渠道已有的 `workspaces.json`，增加可选 `aliases` 映射；没有新增依赖、数据库或配置版本迁移。
- 单独的 `bot.alias.set` RPC 只保存别名并返回更新后的状态，不调用重连、连接配置更新或会话清理。磁盘写入失败时保留原值，界面保留输入并显示错误。
